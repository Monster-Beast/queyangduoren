# 客机显示与交互验收

客机留在 ONI 主菜单，房主载入 Vanilla 殖民地。远端地图使用独立的 IMGUI 视图，按房主给出的格子、管网和复制人样本绘制。角色建立后无需在客机生成世界或载入存档。房主打开殖民地的暂停菜单即可管理房间，关闭暂停菜单后继续使用原版界面。

## 已在本机验证

- Windows 11、Steam 457140，Steam build ID 24423041。本次检查过安装目录中的游戏、Unity、Harmony 和 Steamworks.NET 程序集。菜单接入使用 MainMenu、PauseScreen 与 Game 的实际接口。
- 运行 `dotnet test tests/Core.Tests/Core.Tests.csproj -c Release --filter FullyQualifiedName~ColonyViewTests`，五项通过。覆盖 v4 视图固定字节、主机时钟/暂停/倍速、材料颜色、建筑施工、字符串/对象/管网/位置/任务往返、最坏情况下多语言名称长度、畸形与截断数据，以及复制人视觉插值和移出视野。
- 调整窗口大小时按屏幕尺寸缩放；屏幕坐标映射到左下起算的地图格子。主菜单键盘处理和透明输入区域防止同一次点击落到原生菜单。测试模式仍需实际鼠标/键盘走查。

## 游戏内操作顺序

| 用例 | 动作 | 核对与记录 |
|---|---|---|
| 开房和加入 | 房主载入测试存档，打开暂停菜单，点右上“多人合作”，创建 Steam 房或开发 LAN 房，再恢复时间。客机在主菜单右上加入。 | 记录两端 build、Mod 版本、地图初始位置、连接状态、进入时间。开发端口默认 24714；两账号可用时测试 Steam 邀请运行中游戏及从邀请启动游戏。 |
| 独立视口 | 客机平移和缩放，房主把镜头移向其他区域，再让客机返回打印舱。 | 两端镜头互不影响。切换订阅期间旧地图停止接单，重新收到基线后同一格读数一致。 |
| 框选和执行 | 选择挖掘，框选已揭示的两格岩石。放置梯子；两人同格重复放置，再取消该蓝图。 | 房主只登记一份最终有效订单，等待复制人执行并查看完工后气体进入。先检查“会话状态”的房主回复，再验证显示。队列可停止，顶部状态显示最近处理结果。 |
| 方向与材料 | 切到“建造”，选择一个允许旋转的建筑，打开“方向 / 材料”，选定房主提供的组合，再框选或点击施工。 | 验证施工坐标、朝向和实际物料；另一玩家占用格子或原料失效时，房主按当前状态处理。 |
| 视图与叠层 | 切换地形、温度、氧气、电力、气管、液管、自动化。点击“检查格子”，再选中复制人所在格。 | 核对温度、质量、各方向连线、自动化颜色、设备/任务名和独立视角。未知格子保持遮罩。核查复制人跨格移动、离开视口和重新进入后的标记。 |
| 管线与建筑 | 在线性工具中拖选直线后再拖斜线。用“建筑设置”选择建成的仓库或制造设备，两人同时改筛选、队列或开关。 | 斜线有反馈。建筑菜单按目标和选项版本校验；目标被拆时界面关闭，陈旧修改提示刷新。记录游戏内原生读数。 |
| 殖民地面板 | 打开客机顶部“殖民地管理”，读取、修改已支持项目并返回地图。 | 点击弹窗时地图不会接单；另一端可观察实际修改并验证受限功能。 |
| 输入与字体 | 测 1280×720 和 1920×1080，切分辨率、窗口化、Steam 覆盖层、缩放、拖选、取消与离开。 | 中文、复制人姓名、状态、提示可读，点击地图不会触发原生主菜单；主机关闭面板后可正常点击暂停菜单。 |
| 生命周期 | 客机打开菜单期间房主退出，另开房、重连，切回本地单人存档，重复三次。 | 检查状态、上次选区和临时建筑选项清理、回到主菜单操作正常。本机存档副本未被客机模式覆盖。 |

T04/T05/T07/T08/T09 的真机结论取决于实际执行的场景。单元测试无法验证鼠标命中、画面颜色、Steam 真实邀请或长时间多人操作。性能预算需要真实殖民地测量。候选实现采用 24×16 格固定采样视口，视觉插值只用于复制人标记；网格温度、质量、建筑目标和订单均读取最后确认的房主样本。传输和游戏内实测的其他证据见同目录的会话记录。
