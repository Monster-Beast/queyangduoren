## 复跑

在仓库根目录执行，选择原版、有复制人且具备可挖地块和足量梯子材料的本机 .sav。脚本在 artifacts/qa 下建立临时的游戏副本和独立玩家配置，加载存档副本。开始前须关闭正在运行的游戏。

~~~powershell
$testSave = Read-Host '输入 Vanilla .sav 绝对路径'
.\tests\Integration\Game\run.ps1 -Persistence -SavePath $testSave -TimeoutSeconds 160
~~~

第一阶段运行完整游戏房主和独立 TCP 参考客机。房主收到操作后由原生复制人执行，客机持续接收该区域的状态。下一阶段在房主游戏线程对真实管理、建筑和存档 API 取证。最后启动独立的 Unity 进程和新用户配置，从生成的手动存档重新进入殖民地。这个配置仅安装专用读档驱动。代码会检查 AppDomain 中缺席两份合作程序集，同时比对由房主保存的唯一排班标记。
