## 与同档单人运行的十分钟对照

复用同机、同构建、相同初始存档及 1× 设置的单人采样。两次起始游戏时钟相差 0.0035 秒。比较器排除约一分钟预热，取接下来的十个连续分钟，以游戏时钟增量除以实际用时。

| 场景 | 实际用时（s） | 游戏时钟推进（s） | 游戏秒 / 实际秒 |
|---|---:|---:|---:|
| 单人，仅测试采样驱动 | 600.01213 | 599.5078 | 0.99915947 |
| 联机房主，三个参考客机 | 600.01019 | 598.5400 | 0.99754972 |

按 `100 × (1 − 联机速率 / 单人速率)` 计算，推进速度下降 **0.1611%**，通过下降不超过 15% 的门槛。对照区间的最大分钟泵 p95 为 **0.588 ms**，通过不超过 4 ms 的门槛。速度指标衡量 1× 下的游戏时钟推进，接近实时上限；泵指标衡量该 Mod 的主线程会话处理。

## 本机证据和复现

本轮目录为 `artifacts/qa/game-b2566b8a755646618bcc27a84e2ba330/`。其中 `client.report` 记录逐分钟进展和每端统计，`host.report` 与 `host.log` 记录时钟、泵指标、自动存档及房主检查，`host-memory.csv` 为进程采样，`soak-input.json` 与 `soak-package.json` 保存输入及安装指纹。`comparison.json` 是十分钟比较器输出，`soak-summary.json` 汇总本轮一小时数据。复用的单人原始报告为 `artifacts/qa/game-3b11ea5542584d4380ac674fd6d2d860/solo.report`。

退出普通游戏，在仓库根目录运行。运行器将存档、游戏副本和 Mod 配置放入隔离目录。成功时可看到三个端点进入 Live、每分钟进展、3600 秒 PASS 和原始输入校验结果。

~~~powershell
$fixtureSave = Read-Host '输入上述指纹对应的 Vanilla 存档完整路径'
.\tests\Integration\Game\run.ps1 -SavePath $fixtureSave -SoakSeconds 3600 -TimeoutSeconds 3750
~~~

用运行器打印的 run 目录及相同输入的单人报告复算。比较器写入两项实测值和 `throughputPass`、`pumpPass`。其他检出环境需要重新生成单人报告。[单人采样步骤](../../../tests/Integration/Performance/README.md)

~~~powershell
$run = Read-Host '输入本次长稳 run 目录'
$solo = Read-Host '输入同档单人 solo.report 完整路径'
~~~
