# Klei 764025 单份授权实测

测试机器运行 Windows Steam 基础版《缺氧》，Steam build 26798728。以下各轮依次打开一个游戏进程。运行器复制存档、游戏和玩家配置到隔离目录，结束时核对原始输入指纹。原始存档与 Unity 日志留在本机。

房主共记录 60 个一分钟窗口，每个窗口分别统计 Mod 主线程网络处理时间，最高的窗口 p95 为 **0.870 ms**（门槛 4 ms）。每端平均下行均低于 2 MiB/s。房主进程工作集首次采样 2806 MiB、峰值 2901 MiB。上述回执延迟为本机 TCP 数据。

房主日志中没有 `Exception:`、`[ERROR]` 或 `Assert failed`。游戏生成了 6 个原版自动存档。批处理模式下有 12 条 D3D11 `ReadPixels` 越界提示，分别出现在自动存档缩略图和殖民地延时截图阶段。抽查第 44 周期自动档，512 × 768 的 PNG 能看到殖民地和未揭示区域。

同档单人对照 `game-1267cd076a2c4de3ac24b4b1ff2240b8` 在卸载合作 Mod 后运行。双方预热一分钟，再各取连续十分钟。原版单人推进 599.7422 个游戏秒，三端联机推进 599.2100 个游戏秒，折算同等墙钟时间后，模拟速度下降 **0.0884%**（门槛 15%）。这个数值衡量该档的模拟时钟。单人运行也出现了 2 条相同的 D3D11 提示，缩略图能看见建筑，左侧局部有粉黑斜纹。本文下面的房主和客机界面图取自有窗口的独立测试。
