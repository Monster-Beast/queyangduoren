# Klei 764025 单份授权实测

测试机器运行 Windows Steam 基础版《缺氧》，Steam build 26798728。以下各轮依次打开一个游戏进程。运行器复制存档、游戏和玩家配置到隔离目录，结束时核对原始输入指纹。原始存档与 Unity 日志留在本机。

## 玩家操作范围

在后续房主录制 `game-10850d87a5274314a0cd15637e67fcba` 与客机回放 `game-c641ebf2` 中，客机通过原版工具实际下单清扫、调整优先级 5→7、收获和擦地，四个回执、目标坐标及可见结果吻合。同格种子与跨格建筑的订单各自可寻址。夹具分别观察到穿脱背心时原版渲染符号变化，新打印复制人的详情显示两项技能和两项食药限制。液体管桥出口已满时停止传输，排空后转移 4 kg 水；阀关闭时保持上下游质量，开阀后转移 3 kg。房主记录每个端口的质量，客机比较原版管路的实际读取值。桥和阀设置由隔离夹具控制，流量由游戏模拟计算。[实物、穿戴及订单详情](qa/orders-and-entities.md)

地形与网络独立场景 `game-ca8bb51d9e6b404cb73f09879c21966d` 已经通过。房主与一个真实 TCP 协议端依次核对隐藏格揭示、1000 kg 冰融水、打通密室后氧气流到另一侧（1.228954 kg）、温度传感器绿灯开门和红灯关门、拆线后电路分离以及重接后合并。游戏中的农业研究完成后，原版建造要求中解锁了氧气藻箱（`AlgaeHabitat`）。

同一个 Unity 进程连续三轮原版入房和退房，每轮重新下载基线，回到原版单人后推进游戏时间、生成独立存档、卸载场景，再读回本轮独有的标记。存档依次为 769796、770109、770017 字节。证据目录为 `game-1d59704095414cf5bf0cc7c754d2c6b0`。

在当前 Steam 账号启动游戏后，生产路径创建好友房，核对房主身份、4 人上限、当前 1 人和房间元数据。Steam 原生网络回环收发 44 字节 Ping/Pong，释放两个句柄并退出房间。双账号好友邀请、不同身份 P2P 与跨设备中继仍需另一份授权验收。证据目录为 `game-679b91903ef3480d9afb3aee488b5a35`。

## 复测输入

早期档大小为 763831 字节，SHA-256 为 `F115FE51875668F0AA027A576E3C468291BF5D6B25267227ED9F5FB08A594993`。材料竞争使用的第 39 周期档为 1007308 字节，SHA-256 为 `7AC0563C6AE4032F547F7D189EE8AB7246A4E8E62FC01CD885F1AD72D9AEAC08`。录制保存基线、房主视图及查询回执，回放端用这些数据响应游戏发出的请求。

~~~powershell
.\tests\Integration\Game\run.ps1 -NativeRecord -Persistence -SavePath $earlySave -TimeoutSeconds 210
.\tests\Integration\Game\run.ps1 -NativeReplay $recording -TimeoutSeconds 210
.\tests\Integration\Game\run.ps1 -MaterialCompetition -SavePath $matureSave -TimeoutSeconds 350
~~~

各子系统的预期行为、真实客机回放和双账号首次合流的验收条件见[单份授权清单](../07-single-license.md)。744825 上的一小时结果对应旧版程序，见[历史性能报告](qa/native-soak.md)。

整轮复测可从仓库根目录运行下列入口。它依次完成录制、回放、材料竞争、地形线路、三轮退房、Steam 单号建房、一小时三协议端、同档单人对照和安装回滚。脚本打印各阶段证据目录；某阶段失败会保留该阶段的日志并报错。

~~~powershell
.\tests\Integration\single-license.ps1 -EarlySave $earlySave -MatureSave $matureSave -GameDir $env:ONI_GAME_DIR
~~~
