# Klei 764025 单份授权实测

测试机器运行 Windows Steam 基础版《缺氧》，Steam build 26798728。以下各轮依次打开一个游戏进程。运行器复制存档、游戏和玩家配置到隔离目录，结束时核对原始输入指纹。原始存档与 Unity 日志留在本机。

第 3 周期的小型殖民地，三名复制人。截图取自真实房主，原始分辨率为 3840 × 2160，本文缩为 1280 × 720。左上角、底部工具栏和右侧叠层均由原版渲染。[查看房主截图](qa/host-764025.jpg)
