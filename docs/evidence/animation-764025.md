# 复制人动画验收（基础游戏 764025）

房主运行工作和物理，客机在自己的游戏窗口渲染。核对动作时，要跟踪同一个复制人的存档 ID，同时读取身体、手上物件、身上穿戴、附属特效各自的原版渲染组件。一个组件通过不能替另一个组件验收。

| 玩家能看到什么 | 两端核对什么 | 何时取样 |
|---|---|---|
| 同一个人朝同一个方向施工 | 动作名、实际动作文件、翻转、GPU 帧、世界绘制矩阵 | 起手、循环工作、收手、暂停、恢复及重连 |
| 手持电钻，结束后收起 | 右手挂点是否进入当前帧，最高优先级图像来源是否为原版 `excavator_kanim`，符号可见性 | 房主的真实挖掘窗口和客机对应片段，在两端分别截图 |
| 建造、搬运时手上或胸前的物件 | 相同挂点切换到房主实际绑定的建造工具或搬运图像，收起时旧资源消失 | 从一种工作切换到另一种工作时观察；与电钻分开验收 |
| 光束与矿格接触效果 | 发射位置、目标格、两种特效所用的素材、帧及矩阵 | 同一个房主采样帧和同一个目标格 |
| 技能帽、头发与帽下发型 | 已戴配件、最高优先级符号和可见性；等待取帽时保留房主当前外观 | 原有复制人和入房后新打印的人分别执行戴上、换帽、摘帽、恢复；每阶段保存两张截图 |
| 作业结束、人物离开视口或客机重连 | 旧工具、光束、帽子是否残留，新角色身份与画面中的模型是否一一对应 | 演出切换、移镜后回看、重连读档后再次比较 |

在 `tests/Integration/Game/steam-dual.ps1` 启动的双 Steam 运行中，`dupe-motion.csv` 记录身体动作，`dig-fx.csv` 记录光束和命中效果，`drill.csv` 只记录确实挂有电钻且当前动画帧包含右手挂点的样本。帽子夹具从两端独立读取帽子和头发符号并截取游戏画面。测试在专用殖民地副本中进行，帽子操作由原版技能页处理；暂停期间由夹具调用原版的完成戴帽操作。

各轮的包哈希、截图和实际测量值见[双账号实测记录](steam-dual-764025.md)。新工作种类应追加实际场景，尤其是同时涉及建筑自身动画、人物动作和手持物件的工作。
